## Summary
- While on paper, no money can be lost whatever happens.
- No order is sent without your approval. If you, the phone or the server disappear, the book simply holds what it has.
- The phone held everything: the app, the 6-digit codes and server access. A memorised passphrase and a one-tap Lock were added.
- If there is no action from you for 14 days, buying pauses and a second contact is told. Nothing is sold.
- A dead server can now be rebuilt from a phone, and updates are checked for a valid signature before they install.
- There is a printable one-page emergency card for a second person.

## Key numbers
| What | Number |
|---|---|
| Days without you before buying pauses | 14 (warning at 10) |
| Things sold automatically | none |

## What it means for you
The remaining items are on the go-live checklist in Settings. Set the passphrase, keep the emergency card somewhere your second contact can find it, and tap "I'm here" if you get the 10-day warning.

## How sure are we?
A read-only review of the code and guides; the live server could not be inspected. Fixes are recorded as BF-D82 to BF-D87. The rebuild drill on a second server is still to be done and timed by you.
