## 4. What the owner should know

- **Y-05 is an editor's reading.** After go-live, a later code change gets no new minimum-size live order: the paper and shadow steps, the existing canary record and the owner's approval are what the deploy script checks. If the owner wants each code change proved live at minimum size first, that needs a spec change and a way to place such an order.
- **Y-03:** a withdrawal larger than the managed holdings sells what is held above the one-unit floor and says that the rest cannot be raised. The system never sells the sentinel unit or an unmanaged holding for a withdrawal.
- **Y-01:** tax figures for a sale can be provisional for a while (until the 30 June 2027 value or the quarter's CPI is loaded) and are then corrected by a new row. The year's CGT schedule is marked provisional until then.
- **Open item P10** (Telegram retention) is still unverified, as are the other items in section 21. None of them is changed by this read.

None of these needs a decision before the build.

## 5. The report 29 fixes (Z-01 to Z-05)

Each was checked against the v2.9 text.

- **Z-01** (restore drill): correct. The copy reads no command, sends no check-in, makes no vendor call, writes nothing to the backup or dashboard store, starts no gateway and marks its messages `DRILL`; the mark is set with the halt flag before the runner starts. Section 15 and the BP-16 acceptance test agree with it. The out-of-touch rule of P-01 cannot fire on the copy, because it binds "the runner that reads the bot". The copy still pulls Flex, which is the user's own account data and is not shared state. One edge: the bars of the gap (Y-08).
- **Z-02** (a veto read on a later day): correct. It agrees with OPS-04 ("stamped by Telegram by 11:15") and PRT-27 ("a vetoed intent is not carried"). `/veto SYMBOL` and `/veto ALL` reach buys only, so a carried sell is not stopped by them; `/veto SYMBOL SELL CONFIRM` stops the sell, which PRT-16(a) plans again at the next evaluation. An outage longer than Telegram's retention loses the veto but sets `KILLED` (P-01), and the resume prints the orders.
- **Z-03** (bot unreadable at the start after a long outage): correct; no behaviour changed.
- **Z-04** (a parcel booked late from Flex): correct. One wording edge (Y-07).
- **Z-05** (the runner reads the bot continuously): correct; the heartbeat job already requires the runner to be up on every calendar day.
