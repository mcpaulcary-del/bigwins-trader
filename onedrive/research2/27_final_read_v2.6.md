## 4. The four edits the owner should know about

No report gives the rule for these, so the editor chose the reading that sends fewer orders. None needs a decision before the build.

- **Q-02:** when two runners share an instance, Telegram commands always act on the live ledger.
- **Q-05:** a cost halt or tracking halt that the owner has cleared does not return on the same reading. This is added to open item O18.
- **Q-06:** an order the user cancels in the IBKR app is not replaced that day.
- **Q-07:** a manual sale in a sleeve with both kinds of units takes managed units first.

One clause of Q-01 is also the editor's choice: if the pending commands cannot be read at a start, buys are held and sells proceed, the same split OPS-04 already makes for an undelivered plan.
